# Linux worksheet zoom evidence for GridCraft #1185

Created 2026-10-14 by @allenyllee. All workbook values, image pixels and drawing XML are synthetic, generated by the Rust example `crates/ui-egui/examples/linux_scale_repro.rs` at source commit 75f67361c81e22523ddbee6bd6a830b69626a094. No company workbook, personnel data, copied vendor sample, embedded font, macro or external link is included.

Environment: Linux/GNOME X11; desktop scale and GridCraft interface size 100%; worksheet zoom 50/100/150%; LibreOffice 24.2.7.2. Native window backing pixmaps, never resized. Before and after GridCraft binaries are local 0.6.1 builds both retaining the separate CJK font-path, bitmap-EMF and Chinese import-notice fixes. The new source PR contains only Linux scale work, on main 84acf6293b1dc1fc09837524e035d674eb4d6741. Chinese-reopen capture is from the actually installed fixed binary, a fresh process reading the saved synthetic workbook.

Picture width/height, in screen pixels:

| Zoom | Before | After | LibreOffice |
|---|---|---|---|
| 50% | 128 x 64 | 160 x 80 | 153 x 80 |
| 100% | 256 x 128 | 320 x 160 | 309 x 160 |
| 150% | 384 x 192 | 480 x 240 | 465 x 240 |

The independently measured row pitches are 12/24/36 px in both fixed GridCraft and LibreOffice. At 100%, the Chinese sample's ink height changes from 11 to 15 px; LibreOffice is 15 px. Small text rasterization differences and LibreOffice's approximately 3-4% horizontal image import difference remain. Missing Calibri substitution also affects column width; this evidence does not claim complete layout parity or verify Windows/macOS/BSD/web.

GridCraft control stayed inside the Flatpak private network namespace with a task-only file grant. Its permanent network/broad filesystem deny overrides did not change. LibreOffice used a separate profile, read-only file, disabled macros/link updates and local named-pipe UNO. Both controls were stopped afterward.

Original synthetic workbook/pixels and measurement data are offered under MIT, consistent with the project; software UI depicted in screenshots remains attributed to GridCraft contributors and The Document Foundation/LibreOffice contributors under their respective licences. Screenshots are comparison evidence, kept outside the source PR. No vendor source code was read/copied.
